## 3.2 手写 Agent Loop

```python
while True:
    response = llm(messages, tools=tools)

    if response.is_final:
        return response

    for tool_call in response.tool_calls:
        result = execute_tool(tool_call)
        messages.append(result)
```

# Phase 6：Workflow vs Agent

## Workflow

```text
User
 ↓
Classify
 ↓
Search
 ↓
Generate
 ↓
Review
 ↓
Send
```

## Agent

```text
User
 ↓
LLM
 ↓
决定下一步
 ↓
Tool
 ↓
观察
 ↓
继续决定
 ↓
Final
```

## Workflow 模式

```text
Sequential
Parallel
Routing
Conditional
Loop
Retry
Human Approval
```

## 选择原则

Workflow 适合：
- 流程明确
- 步骤固定
- 业务规则强
- 可预测

Agent 适合：
- 任务开放
- 路径不确定
- 动态 Tool Selection
- 动态决策

生产环境通常采用：

```text
Workflow
  ↓
Agent
  ↓
Workflow
  ↓
Human Approval
  ↓
Agent
```

# 最重要的学习原则

## 原则 1：不要一上来学框架

错误：

```text
LangChain
 ↓
LangGraph
 ↓
Agent
```

正确：

```text
LLM
 ↓
Tool Calling
 ↓
Agent Loop
 ↓
RAG
 ↓
MCP
 ↓
Workflow
 ↓
Agent Runtime
 ↓
Framework
```

## 原则 2：每学一个核心概念自己实现一次

```text
Tool Calling → 手写
Agent Loop → 手写
RAG → 手写
MCP → 手写
Workflow → 手写
```

再使用：

```text
OpenAI Agents SDK
LangGraph
LangChain
LlamaIndex
```

## 原则 3：不要盲目追 Multi-Agent

先问：

> 单 Agent + Tools 是否已经足够？

如果可以，就不要 Multi-Agent。

## 原则 4：Evaluation 和 Observability 要尽早进入项目

从项目早期就加入：

```text
Evaluation
Tracing
Metrics
Logging
```

## 原则 5：Security 不是最后补丁

从设计阶段加入：

```text
Permission
Sandbox
Approval
Credential Isolation
Audit
Prompt Injection Defense
```
